# 北证证券终端 · DEMO（920999 N星澜）

单一 HTML 纯前端演示页：`index.html`。无构建、无依赖、无网络请求。

## 1. DEMO / 模拟边界

- 页面顶部固定 `DEMO` 标识，全页行情、五档盘口、成交、资金、持仓、委托均为**合成演示数据**。
- 不连接交易所、券商、行情源或任何网络接口（页面显示「网络 0 请求」），不产生真实交易，不构成投资建议。
- 规则实现范围仅限 **3.6.5(2)(3)**：无价格涨跌幅限制股票的大宗交易申报价格区间（均价 = 已成交金额 ÷ 已成交股数；上限 = min(均价 × 130%, 已成交最高价)；下限 = max(均价 × 70%, 已成交最低价)），边界含本数，越界 0.01 元拒绝。
- 公告 34 号涉及的 4.5.1—4.5.4 条（风险警示及退市整理股票）**不在**本页实现范围内。
- 标的 920999 N星澜标注为「无价格涨跌幅限制（新股上市首日，模拟）」，其余标的为静态合成行情。

## 2. 启动与交互

- 启动：直接用浏览器打开 `index.html`（本地 file 打开或静态托管均可），无需 `npm install`、无构建步骤，也不需要启动本地服务器。
- 首次打开为**干净初始状态**：无任何预置委托、订单流水为空，自检控制台已移除。
- 交互：
  1. 左栏自选列表切换标的（仅 920999 具备完整盘口与规则校验）。
  2. 「委托下单」面板切换 `限价委托` / `大宗委托` 两个页签，选择买/卖方向。
  3. 大宗页签提供 `填下限` / `填上限` / `填均价` / `下限 −0.01` / `上限 +0.01` 快捷填充按钮。
  4. 「运行边界校验」现场跑 5 个价格用例（上限、上限 +0.01、下限、下限 −0.01、区间中值），结果表格显示预期 / 实际 / PASS。
  5. 委托流水表实时反映状态、冻结说明与撤单入口。

## 3. 订单编号与重置语义

- 委托编号格式固定为 `D20261112-NNNN`（`D` + 交易日 `20261112` + 4 位序号，从 `0001` 递增），由单一计数器 `nextOrderNo()` 生成，页面内**全局唯一**、不复用、不因撤单回收。
- 页面重载（刷新）等价于全新会话：计数器归零、流水清空、账户回到初始值。
- 「重置虚拟账户与委托流水」按钮：恢复初始资金 ¥5,000,000.00、持仓 200,000 股（成本 9.60）、冻结资金 / 冻结股份归零、委托流水清空、边界校验区回到「尚未运行」状态；编号计数同样归零，下一笔重新从 `D20261112-0001` 开始。该按钮只作用于前端内存状态，不触达任何外部系统。

## 4. 撤单与冻结语义

- 仅状态为 `已报`（限价挂单）或 `已受理`（大宗申报）的委托提供「撤单」入口；`已成交`、`已拒绝`、`已撤` 无入口。
- 买入挂单：提交时 `现金 → 冻结资金`（现金减少、冻结等额增加），总资产不变；撤单时冻结资金全额回到现金并记录撤单时间与释放金额。
- 卖出挂单：提交时冻结等量可用股份（持仓总数不变、可用减少、冻结增加）；撤单时释放冻结股份。
- 撤单后状态置为 `已撤`，写入撤单时间与释放说明；重复撤单被拒绝且账务不变。
- 恒等式：买入类「现金 + 冻结」在提交与撤单前后守恒；卖出类「可用 + 冻结」始终等于持仓总数。
